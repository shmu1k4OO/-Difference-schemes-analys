# -Difference-schemes-analys

Программа применима к волновым уравнениям с краевыми условиями Дирихле.
Аппроксимация начального условия сделана со вторым порядком точности разложением в ряд Тейлора
в окрестности точки ноль по tau.

Для тестирования нужно ввести свою тестировочную функцию и выбрать один из двух решателей:

solve_with_method_1

solve_with_method_2

при этом они отличаются по сигнатурам на один параметр.

В программе предусмотрен flag:

значение 1 выставляем в том случае, если схема условно-устойчива, даёт возможность проанализировать графики решений с невыполненным условием устойчивости.

значение 2 выставляем в случае абсолютной устойчивости.
